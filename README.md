# Sudopuzzle — Blocos 9×9

Jogo de encaixar blocos num tabuleiro 9×9. Complete linhas, colunas ou quadrados 3×3 para limpar e somar pontos.

**Jogar:** https://itowers.github.io/sudopuzzle/

## Instalar no iPhone (offline)
1. Abra o link acima no Safari.
2. Compartilhar → **Adicionar à Tela de Início**.
3. Abra uma vez com internet; depois funciona em modo avião.

## Recursos
- Arrastar e soltar com prévia e destaque das áreas que serão limpas
- Combos e sequências com multiplicador
- Chaves a cada 100 pontos e recorde salvo no aparelho
- Desfazer a última jogada e dica de melhor encaixe
- PWA com service worker (funciona offline)
