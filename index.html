Como jogar

Arraste as peças para o tabuleiro 9×9.

Complete uma linha, uma coluna ou um quadrado 3×3 para limpar.

Limpar várias áreas de uma vez dá combo; limpar em jogadas seguidas dá sequência (multiplicador).

A cada 100 pontos você ganha uma chave. O jogo acaba quando nenhuma peça cabe.
